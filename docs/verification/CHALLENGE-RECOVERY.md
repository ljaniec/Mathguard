The old policy-v1, activate/agent-run/tests-run route proposals and durable design were moved into an explicitly unsupported historical document; the current contract no longer relies on a status banner to resolve contradictory examples.

Two clarifications to automated product-review wording: restart returns to the nonzero seeded genesis; the formal account/policy theorems are generic, while the current adapter fixes a three-account demonstration. Also, owner credentials may submit actions; the authority property is that agent credentials cannot issue approval. Global vector quotas remain an explicit single-owner scope limit; operators can raise a limit by validated new epoch without resetting accounting.
